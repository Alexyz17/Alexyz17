## 👋 Sobre mí

Soy desarrollador full-stack con **3 años de experiencia profesional**, doble titulación en **DAM + DAW** y actualmente como Junior Software Developer en **Videoatencion SL**. Me especializo en construir plataformas web completas: desde el backend con Java o Laravel hasta aplicaciones móviles con Kotlin.

Lo que me diferencia es el **rango**: he pasado de videojuegos RPG en Java, a apps Android con Firebase, a ERPs con Spring Boot, a plataformas ed-tech en producción con React + Laravel. Aprendo rápido cuando el problema me engancha — y casi siempre me engancha.

- 🔨 Construyendo **[darkcode.dev](https://darkcode.dev)** — plataforma de cursos de programación con Laravel 13, React 19 e Inertia
- 💼 Junior Software Developer en **Videoatencion SL** (Feb 2026 – presente)
- 🏢 Antes en **Sofyman Sistemas SL** (Jun–Dic 2025) y **Proogresa SL** (Nov 2024–Feb 2025)
- 📍 **Terrassa, España** · 100% remoto
